Bantuan

WebSocket Terminal adalah alat untuk menguji koneksi WebSocket, mengirim dan menerima pesan secara real-time.

  • Masukkan URL WebSocket (ws:// atau wss://)
  • Klik Connect untuk membuka koneksi
  • Ketik pesan dan tekan Enter atau tombol Kirim
  • Gunakan tombol Perintah Cepat untuk template pesan umum
  • Statistik menampilkan jumlah pesan dan durasi koneksi

Server echo akan mengirimkan kembali pesan yang Anda kirim. Untuk server lain, periksa dokumentasi protokolnya.
