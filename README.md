# WebSocket Terminal

Interactive WebSocket client for testing and debugging real-time connections.

## Features
- Connect to any WS/WSS endpoint
- Custom protocols and headers (JSON format)
- Real-time message send/receive with bubble UI
- Quick command buttons (ping, echo, subscribe)
- Connection statistics (sent/received, duration)
- Persistent settings (localStorage)
- Clean terminal-like interface

## Tech
- HTML5, Tailwind CSS, Vanilla JS
- Native WebSocket API
- No build step required

## Usage
1. Open `index.html` in browser
2. Enter WebSocket URL (e.g., `wss://echo.websocket.org`)
3. Click Connect
4. Send messages

## Deploy
Static site, ready for GitHub Pages.
